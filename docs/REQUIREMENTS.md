# Penguin Dyle — 要件定義書

## 1. プロジェクト概要

| 項目 | 内容 |
|------|------|
| プロジェクト名 | Penguin Dyle（ペンギン大流） |
| 種別 | ブラウザ完結型 AI コーチング日記アプリ |
| 公開先 | GitHub（パブリックリポジトリ） |
| ライセンス | MIT License |
| 言語 | 日本語（UI・プロンプト・ドキュメント） |

### 1.1 コンセプト

ユーザーが日々の出来事や気持ちを AI キャラクター「ペンギン大流（ダイル）」と会話形式で振り返り、その会話を元にダイルが自省的な日記を生成する。量子力学に着想を得た感情モデルにより、感情の推移を連続的に記録・可視化する。

### 1.2 設計原則

- **完全クライアントサイド**: サーバ不要。推論・保存すべてブラウザ内で完結する。
- **マルチプロバイダ対応**: ローカル推論（WebGPU）と外部 API（Gemini / OpenAI / Claude）を切替可能。
- **APIキーはユーザー管理**: API モード利用時、各ユーザーが自分のキーを入力。キーは localStorage にのみ保存し、サーバには送信しない。リポジトリにキーは含めない。
- **プライバシー重視**: 日記データは localStorage にのみ保存。API モードでも送信されるのはプロンプトと会話のみ。
- **カスタマイズ可能**: キャラクター設定は `js/persona.js` の 2 定数を書き換えるだけで差し替え可能。

## 3. 動作環境

### 3.1 必須要件

| 項目 | 要件 |
|------|------|
| ブラウザ | Chrome 113+ / Edge 113+（WebGPU 対応必須） |
| メモリ | 16GB 以上推奨 |
| ストレージ | 初回に 3〜4GB のモデルダウンロード領域 |
| ネットワーク | 初回起動時のみ必要（モデル取得後はオフライン可） |

### 3.2 推奨環境

- Apple Silicon Mac（M1/M2/M3/M4）
- NVIDIA GPU 搭載 Windows/Linux（WebGPU ドライバ対応）
- Wi-Fi 環境（初回モデルダウンロード時）

## 4. 機能要件

### 4.1 会話ページ（index.html）

| ID | 機能 | 詳細 |
|----|------|------|
| F-01 | 初回チュートリアル | 初回アクセス時に 4 ステップのウォークスルーを表示。スキップ可。 |
| F-02 | 自動挨拶 | モデル準備完了後にダイルが自動で挨拶メッセージを生成。 |
| F-03 | ユーザーメッセージ送信 | テキストエリアに入力（最大 4000 文字）、送信ボタンまたは Ctrl+Enter で送信。 |
| F-04 | AI 応答生成 | ユーザー入力を受け、感情分析を実施したうえでダイルの応答を生成。 |
| F-05 | 会話自動保存 | リアルタイムで localStorage に保存。 |
| F-06 | 日記生成トリガー | 「日記を書いてもらう」ボタンで生成パイプラインを起動。 |
| F-07 | 生成中の離脱防止 | ナビゲーション無効化 + beforeunload 警告。 |
| F-08 | ユーザー名入力 | サイドバーに名前入力フィールド。プロンプトに反映。 |
| F-09 | 日時入力 | 手動入力可。未編集時は 30 秒ごとに自動更新。 |
| F-10 | テーマ切替 | ライト/ダークモードのトグル。 |

### 4.2 日記ページ（diary.html）

| ID | 機能 | 詳細 |
|----|------|------|
| F-11 | 新規日記の表示 | 生成直後の日記を吹き出し形式で表示。保存ボタン。 |
| F-12 | 日記の蓄積表示 | 保存済み日記を新しい順に一覧表示。 |
| F-13 | 会話履歴の閲覧 | 各日記に対応する会話履歴を折りたたみ表示。 |
| F-14 | 感情パラメータ表示 | 量子 3 軸 + 古典 2 軸をバーチャートで表示。 |
| F-15 | 感情パラメータ削除 | 各パラメータを個別に削除可能。 |
| F-16 | 日記エントリ削除 | 個別のエントリを削除可能。 |
| F-17 | 空状態表示 | 日記 0 件時の案内メッセージ。 |

### 4.3 記録ページ（archive.html）

| ID | 機能 | 詳細 |
|----|------|------|
| F-18 | カレンダー表示 | 月表示カレンダー。日記がある日にドット表示。 |
| F-19 | 感情グラフ | 5 軸の個別ミニチャート。 |
| F-20 | グラフ期間切替 | 7 日 / 1 ヶ月 / 全期間。 |

## 5. 量子感情モデル仕様

各軸は 1 量子ビット `|ψ⟩ = α|0⟩ + β|1⟩` として表現。
- 初期状態: `α = β = 1/√2`（P = 0.5）
- 観測確率: `P(positive) = |α|²`
- 更新: Ry(θ) 回転ゲート、`θ = -impact × π/6`
