# Superposition — 量子感情モデル搭載 AIキャラクター日記生成システム

量子力学の確率振幅でAIキャラクターの感情を管理し、ユーザーとの対話から日記を生成するエージェント型システム。

## 概要

カフェ「Superposition」のマスター・カイが、常連客（ユーザー）から毎日の出来事を聞き、それを分析・内省して日記を書く対話型システムです。

### 特徴

- **量子感情モデル**: 感情を量子ビットの状態ベクトル（確率振幅）で管理。Ry回転ゲートで緩やかに変化させ、古典層で履歴を保持
- **対話型生成**: ユーザーの日報入力 → 感情分析 → 量子状態更新 → 日記生成 のリアクティブなループ
- **構造化エピソード記憶**: 日記からJSON形式で出来事・学び・未解決課題を抽出し、直近2日は詳細、それ以前は要約として管理
- **Reflectionモジュール**: 前日の自分へのメタ認知的フィードバックを生成し、日記の連続性を担保
- **感情軌跡の可視化**: 7日間の感情変化を折れ線グラフで出力

## システムアーキテクチャ

```
ユーザー入力（日報）
    │
    ├─→ [感情影響度分析] LLMがJSON出力
    │         │
    │    [量子感情モデル] Ry回転ゲート適用 → 状態ベクトル更新
    │         │
    ├─→ [Reflection] 前日の内省を生成（Day 2以降）
    │         │
    ├─→ [日記生成] Persona + 感情 + 記憶 + 内省 + ユーザー入力 → 日記
    │         │
    └─→ [エピソード記憶] 日記からJSON抽出 → 構造化保存
```

## 量子感情モデル

3つの感情軸を量子ビットの重ね合わせ状態で表現：

| 軸 | |0⟩ ポジティブ | |1⟩ ネガティブ |
|----|-------------|-------------|
| q1 | 自信 | 不安 |
| q2 | 好奇心 | 倦怠 |
| q3 | 冷静 | 焦燥 |

- 初期状態: 均等な重ね合わせ `(1/√2, 1/√2)`
- 更新: イベントの影響度 × Ry回転ゲート（回転角上限 ±π/6）
- 前日の状態ベクトルを古典的に保持して引き継ぐことで急変を防止

## 技術スタック

| 要素 | 選定 |
|------|------|
| LLM | Gemini API 経由 Gemma 4 (31B or 26B MoE) |
| 実行環境 | Google Colab |
| 量子計算 | NumPy（状態ベクトル・回転ゲートを自前実装） |
| 可視化 | matplotlib |
| 出力 | HTML（ブログ風UI + 感情バー + グラフ埋め込み） |

## セットアップ

### 1. APIキーの取得
1. [Google AI Studio](https://aistudio.google.com/) でGemini APIキーを取得
2. Google Colabのシークレットに `GEMINI_API` として登録

### 2. 実行
1. `quantum_diary_agent.ipynb` をGoogle Colabで開く
2. セル1から順に実行
3. セル8でユーザー入力を求められるので、7日分の日報を入力
4. セル9-10でグラフとHTMLが生成・ダウンロードされる
